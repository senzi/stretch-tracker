# FLEX//OS — 摸到地板 · 12 周柔韧性训练终端

> 一个零依赖、纯前端的柔韧性训练打卡与体前屈成绩跟踪工具。目标：指尖触地。

纯 HTML + CSS + JavaScript 单页应用，无构建步骤，无后端，数据只存在你自己的浏览器里。

## 功能

- **每日训练流程**：12 周计划里的 6 个动作（热身 → 动态摆腿 → 站姿体前屈 → 坐姿单腿前屈 → 仰卧毛巾抱腿 PNF → 婴儿式放松），逐项勾选打卡
- **体前屈成绩记录**：记录指尖离地距离（cm），填负数会自动按正数处理；目标 = 0（触地）
- **预期对照**：设置起始基线后，趋势图绘制乐观 / 基准 / 保守三档预期曲线（8 / 12 / 17 周），实时显示「领先 / 落后预期多少 cm」和预计还需几周触地
- **历史与趋势**：训练档案、连续打卡天数、完成率 × 成绩趋势图
- **数据备份**：一键导出 / 导入 JSON（localStorage 存储，导出文件可跨浏览器迁移）
- **昼夜主题**、响应式布局（手机可用）

## 快速开始

直接用浏览器打开 `index.html` 即可，或者部署到任意静态托管（GitHub Pages / Cloudflare Pages 等）。

## 训练计划

内置训练计划详见 [`摸到地板·12周柔韧性训练计划.md`](摸到地板·12周柔韧性训练计划.md)，包含：

- 动作原理与科学依据（静态拉伸剂量、PNF 收缩-放松、每周约 10 分钟最优等）
- 12 周进阶节奏与每周自测记录表
- 三条安全红线与常见错误自查

页面右上角「文献」按钮可查看计划所依据的 5 篇参考文献标题与 DOI。

## 数据说明

- 所有数据（打卡记录、成绩、基线、档位）均保存在浏览器 `localStorage`，**不会上传到任何服务器**
- 清除浏览器数据前请先「导出」备份 JSON
- 换设备：导出 → 新设备打开页面 → 导入
